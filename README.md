Simple Calculator
A simple calculator program made with Python.

Features
- Performs basic calculations
- Takes input from the user
- Displays the calculation result
- Simple command-line interface

Technology
- Python

How to Run
1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

python calculator.py

4. Follow the instructions shown in the terminal.
Purpose
This project was created to practice Python basics, user input, calculations, and programming logic.
